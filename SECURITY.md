# Security

Use GitHub private vulnerability reporting if available. Otherwise open a minimal issue asking for a private contact without posting credentials or exploit details involving private data.

The app operates on explicitly pasted summaries. It does not upload, store, read private agent files or make model requests. This is not a general secret scrubber or a proof that your browser/host/extensions are trustworthy. Review docs/privacy.md and do not use raw transcripts as a public issue attachment.

Report input-triggered script execution, unintentional requests/storage, unsafe exports or parser resource-limit failures with synthetic reproductions. Dependency-free runtime does not remove the need to review the page source or development dependencies.
