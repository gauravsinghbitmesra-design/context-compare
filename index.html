    A useful comparison takes one small change.

    1. Capture the baseline. Run /context in a fresh session. Copy its category summary.
    2. Change one thing. For example, review a long memory file or an optional MCP connection you do not need.
    3. Repeat the conditions. Capture a second fresh-session summary. Compare here, then test the workflow still works.
