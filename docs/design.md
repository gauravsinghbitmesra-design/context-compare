# Context Compare v0.1 — design and plan

Date: 2026-11-05. User delegated analysis, product choice, development, testing, GitHub publication and a practical launch plan. Build an instant browser utility around measured before/after reported context, rather than another installable dashboard. No account or API key. Original MIT code.

## Product
Paste two Claude Code /context summaries. Parse recognized top-level summary categories, compare shared categories, flag inconsistent/missing data and export aggregate-only Markdown/JSON/PNG. Default mode compares setup categories (system prompt, system tools, MCP tools, custom agents, memory files, skills); optional mode includes messages. Free space/autocompact buffer never counted as consumed categories. Missing categories never become zero. All numbers are reported/possibly rounded observations, not billing, quota, actual wire tokens or proven savings. Same model/version/workload must be confirmed by the operator; even then this is not controlled validation.

## Architecture
No runtime dependencies: core.js UMD pure parsing/comparison/export; app.js DOM renderer with textContent only; styles.css; index.html. Node 22/24 tests. Browser works on GitHub Pages and local static files/server; test direct-file access before claiming it. No network APIs, local/session storage, cookies, service workers, analytics, automatic clipboard reads or agent configuration changes. Initial page files are fetched normally on hosted site. CSP connect-src none and local assets. Clear inputs/control resets state. Maximum 64KiB per input and1000lines; bound category and number counts. No raw unknown labels or lines in exports/errors. Inputs may be private: browser extensions and host trust remain outside scope; no claim that heuristic parsing anonymizes all data.

## Core contract
parseSnapshot(text) -> {schemaVersion:1,categories:[{id,label,tokens,approximate,roundingHalf}],usedTokens:number|null,capacityTokens:number|null,warnings:[fixed strings],ignoredLines:number,approximate:boolean}. Recognize anchored colon/space lines and Markdown/box summary table with Category/Tokens headers. Restrict known categories and stop before per-tool/per-file tables. Allow k/m/comma integer values and optional tokens/percent annotations; reject negatives/nonfinite/unsafe/extraneous expressions. Header Total: used / capacity tokens. Support JSON {schemaVersion:1,categories:{canonical_id_or_label:number_or_token_string},usedTokens?:number,capacityTokens?:number}. Unknown keys generate fixed warnings; duplicate aliases are errors. Free/Buffer kept separate. Round-display uncertainty used for sum-vs-total validation. Totals/remaining inconsistencies warning. Never infer total from incomplete category coverage.

compareSnapshots(before,after,{mode:'setup'|'all',conditionsMatched:boolean=false}) -> {mode,rows:[{id,label,before:number|null,after:number|null,delta:number|null,included:boolean}],beforeSubtotal,afterSubtotal,delta,percentChange:number|null,commonCount,warnings:[strings],conditionsMatched}. Sum shared nonreserve categories only. No common categories -> concise error. Partial coverage and inconsistent totals make warnings visible, not silently normalized. Different capacities/model/versionconditions unconfirmed -> warning. Percent is on selected common categories only, not all usage. makeMarkdown(result,{demo:boolean}) and makeExport(result,{demo:boolean}) export only aggregate known labels/numbers/warnings; no raw snapshot text or inferred cost.

## Experience
One page, light warm paper/ink style, strong hierarchy. Header one-sentence purpose, privacy note, visible synthetic example buttons (leaner/unchanged/missing categories), two labeled inputs, comparison mode and operator condition checkbox, compare button. Results: reported before/after selected-category totals and delta, paired bars/table with numeric values, warnings, concrete evidence-oriented next steps with links to official docs. Copy Markdown and download PNG card/JSON. Sample data clearly labeled in screen and exports. Input edits invalidate old result so stale exports impossible. Copy/download disabled when no valid result. Errors never echo raw inputs. Keyboard/mobile/empty/error paths tested. No claims of automatic actual Claude/Codex integration; manual JSON usable for other tools if categories match.
